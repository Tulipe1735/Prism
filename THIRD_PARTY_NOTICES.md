## Bundled fonts

The workbench ships the following fonts in `src/workbench/ui/assets/fonts/` and
`dist/workbench-ui/assets/fonts/`. Each font is licensed under the SIL Open Font
License, Version 1.1. The bundled license files include the copyright notices and full
license terms.

- **Inter**: variable Latin and Latin Extended fonts from
  [@fontsource-variable/inter 5.3.0](https://github.com/fontsource/fontsource), based on
  [Inter](https://github.com/rsms/inter). See `Inter-OFL.txt`.
- **Source Han Serif SC 2.003 (思源宋体)**: the Simplified Chinese variable WOFF2 font
  from
  [Adobe Fonts](https://github.com/adobe-fonts/source-han-serif/tree/release/Variable/WOFF2/OTF).
  See `SourceHanSerif-OFL.txt`.
- **JetBrains Mono 2.305**: normal and italic variable WOFF2 fonts from
  [JetBrains](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts).
  See `JetBrainsMono-OFL.txt`.
