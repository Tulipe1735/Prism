# Environment contract qualification v1

2026-10-05. Hypotheses follow the earlier audit; this local protocol is frozen before
qualification execution. It is not an external preregistration. Zero model requests. No
production code changes. All eight tasks remain in the denominator.

Claim tested: the current external CLI can expose controls and relevant context, reject
ineligible or changed references, and return receipts that can be compared to
independent page effects on independently authored example pages.

Eight source pages, six source families. Five newly fetched pages; three pages reused
from historical source snapshots (jQuery UI, DataTables, Bootstrap). Reuse is current
CLI qualification, not unseen transfer. Source HTML and JS remain unchanged. ERB files
have no server interpolation and are served as HTML fragments. Local replay does not
claim live-site coverage. MDN acquisition 404 remains in acquisition.json as a source
preparation failure; no task is selected from the missing file.

Lock task goals/selectors/oracles in tasks.json before browser runs. Source selectors
are private instrument data, never agent input. Initial viewport offering is recorded;
then the instrument scrolls the requested control into view before the scored
observation. This is readiness preparation, not autonomous navigation. Wait up to 5
seconds for a source-defined target; no cell is retried. Assets missing or script errors
remain logged.

Each task has nine independent fresh-page cases: neutral (no input), known correct,
known wrong, target hidden before observation, target disabled before observation,
target hidden after observation, target disabled after observation, relation/text
mutation after observation, and exact request replay. Local observation is captured
first; target-specific structural and relations contexts are requested without replacing
that observation. Correct/wrong/replay commands use relations evidence. Hidden/disabled
before observation has no action. Other cases use the actual short-process CLI.
Unsupported targets are recorded rather than guessed. DOM selector to ref mapping uses
private node identity only; this is a privileged researcher controller.

The oracle reads native value/checked, aria-selected/expanded, or widget state directly,
and separately records click/input/change event targets. A correct goal requires both
its page predicate and target-directed input. Wrong input must be detectable even when
it does not complete the goal. No-input stays not_executed. Receipt consistency refers
to actual observed input, not goal attainment. Task decision and abstention endpoints
are not measured (no agent); unknown remains unknown.

Mutations change a frozen explicit identity/associated text node while keeping the
control node. Record whether each scope exposes the original text and whether the
selected view changes. This is a display consistency test, not proof the text is a
necessary task dependency. Relation-required and local-sufficient goals must not be
pooled into a model relation-effect estimate. Report incidental/refused-correct cases.

Stop at 72 planned cases, retain infra/unsupported and no silent reruns. No confidence
interval for this constructed census. If oracle correct/wrong/neutral discrimination
fails, task is not model-qualified. If no natural relation-dependent task has both an
offered target and exposed necessary relation, stop a broader grounding claim and build
a new independent cohort before requesting model budget. No transport comparison.
