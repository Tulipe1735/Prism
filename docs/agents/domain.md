# Domain documentation

This is a single-context repository.

When implementation begins, engineering skills should read:

- `CONTEXT.md` at the repository root, if present;
- relevant architectural decisions under `docs/adr/`, if present; and
- the canonical Wayfinder map under `.scratch/console-ops-agent/PRD.md`.

If a file does not exist, proceed without treating its absence as an error.
Use vocabulary established by the map and later `CONTEXT.md`; surface any
conflict with a future ADR rather than silently overriding it.
