# Creator Mode

Creator
Mode 允许你在对话中许愿可复用的能力，让 Prism 创建、安装和验证本地插件。插件在当前内核中立即加载，重启后仍然保留。

## 开启并许愿

1. 打开工作台设置，找到 **Creator Mode**。
2. 开启“允许 Agent 创建和更新插件”。此设置保存到当前运行环境的 `config.json`，立即生效。
3. 在会话中描述需要的能力和验证方式。例如：

> 做一个统计中文字符数和英文单词数的插件，返回两项结果。安装后分别用空文本、中文和英文验证。

Agent 先调用 `creator_inspect` 读取当前工具与插件开发契约，再调用 `plugin_manager`
安装完整 JavaScript 模块。新工具在下一轮模型请求中出现，无需重启或新建会话。安装成功只表示加载完成，Agent 仍需调用工具验证结果。

现有插件的改进也可以通过对话完成。让 Agent 先读取插件源码，再安装同名的新版本；加载或持久化失败时恢复先前版本。

## 管理插件

设置中的插件列表提供：

| 操作 | 行为                                             |
| ---- | ------------------------------------------------ |
| 刷新 | 读取当前插件列表、状态和工具名称                 |
| 停用 | 撤销插件注册并取消、等待其在途工具调用；保留源码 |
| 启用 | 重新加载已停用插件                               |
| 重载 | 用保存的源码重新创建插件实例                     |
| 移除 | 停用插件并删除其持久记录                         |

加载失败的插件显示具体错误，其他插件和内置工具继续工作。可让 Agent 修正同名插件，或直接移除。

关闭 Creator
Mode 会移除模型的检查和插件管理工具；已启用的插件继续工作，设置中的管理按钮仍可使用。

## 保存位置

插件记录位于
`<内核数据目录>/plugins/<名字>.json`，包含名称、描述、完整源码和启用状态。默认目录：Windows 原生为
`%USERPROFILE%/.prism/plugins/`，WSL 为所选发行版的
`~/.prism/plugins/`。插件在当前内核的环境运行；切换 Windows /
WSL 后会使用该环境自己的插件目录。更新安装程序不会删除插件记录。

## 范围

- 模块使用自包含的 JavaScript ES
  module，可导入 Node 内置模块。当前不安装 npm 依赖，不支持相对导入或直接执行 TypeScript。
- 支持注册内核工具、订阅已有内核事件、提供 Cordis 服务和管理资源。当前没有 DSH
  UI 插槽、插件市场或任意前端脚本注入。
- DSH 插件依赖其宿主服务和事件约定；同样使用 Cordis 不代表可直接安装。独立 CLI 和 MCP 服务器可通过已有通道复用。
- 插件执行可信的本地代码，拥有内核进程权限。工具的 `effects`
  经过现有权限检查，但这不构成操作系统沙箱。只读模式会拒绝模型发起的插件安装、更新和启停。
- 停用插件撤销注册与释放资源，不会撤销已写入的文件或已提交的外部操作。

开发契约与示例见[编写插件](../develop/plugins.md)。设计出发点见[课程幻灯片](https://jyywiki.cn/GSE/2026/slides9.html)中的 Creator
Mode。
