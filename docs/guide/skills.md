# Skills 加载

技能（skill）是教内核完成特定工作流的说明文件。内核按目录约定发现技能，读取 `SKILL.md`
前置元数据中的名称与描述用于选择，正文在需要时按需加载。

## 目录约定与优先级

每个技能是一个目录，目录内的 `SKILL.md`
是其入口。扫描顺序即优先级，同名技能由先发现的根目录提供：

| 优先级 | 级别   | 目录                                      |
| ------ | ------ | ----------------------------------------- |
| 1      | 项目级 | `<工作区>/.agents/skills/<目录>/SKILL.md` |
| 2      | 全局   | `~/.agents/skills/<目录>/SKILL.md`        |
| 3      | 预置   | 随 Prism 分发的 `skills/<目录>/SKILL.md`  |

- 项目级优先于全局：同一工作区内换用项目自己的流程说明时，不必删除全局技能。
- 全局目录沿用 agent skills 的通用约定，已有的技能无需搬运即可被内核发现。
- 同一根目录内按目录名排序，同名时取排序在前的目录。
- 根目录不存在属于正常情况，不算错误。

## SKILL.md 格式

```md
---
name: release
description: 发布新版本时使用；包含打标签与发布检查清单。
---

正文：步骤、约定与检查项。正文在技能被选中后才加载。
```

- `name`：必填，技能标识，也是加载正文时使用的名字。
- `description`：必填，说明何时使用该技能，用于选择。
- 正文：frontmatter 之后的内容；返回前去除首尾空白。

frontmatter 是 YAML，支持多行描述（折行或块标量）。除 `name` 与 `description`
外的字段被忽略；技能自带的其他文件（脚本、模板）不自动执行，由正文说明如何使用。

## 损坏与缺失

扫描跳过不可用的技能，在报告中给出路径与原因，并继续处理其余技能：

- 目录内缺少 `SKILL.md`；
- 缺少 YAML frontmatter，或 frontmatter 不是合法 YAML；
- `name` 或 `description` 缺失、不是字符串或为空；
- 文件无法读取（权限、损坏的链接等）。

被跳过的技能不出现在技能列表中。同名但优先级较低的技能不进入列表，也不作为错误报告。

## 预置技能

`skills/prism/SKILL.md` 随包分发，内核默认可见；用户级或项目级同名技能会覆盖它。

## 模块接口

`src/skills/loader.ts`：

- `scanSkills({ workspace, home?, bundled? })`：按优先级扫描各根目录，返回
  `{ skills, problems }`；`home` 默认用户家目录，`bundled` 默认本包的 `skills`。
- `loadSkill(skill)`：按需读取正文；文件此时不可用时抛出带原因的 `Error`。
