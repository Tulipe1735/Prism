# Prism 首版需求：个人 coding agent

日期：2026-10-18。状态：已对齐，实施以此为准。决策背景见各 ADR。

## 产品定位

Prism 是长期自用的个人 coding
agent。桌面工作台运行在 Windows，内核在 WSL 中围绕用户指定的工作区推进开发任务：读代码、改文件、执行命令与测试，并核查任务结果。

桌面是首版唯一产品入口；内核保持 headless 可调用。旧研究助手已删除，不复用。

## 首版范围

包含：

- 轻量工作台：工作区、会话、聊天、工具执行过程、代码改动与产物查看、审批交互。不含内置代码编辑器、文件树与交互终端。
- 编码基础：工作区文件读写、命令执行（WSL 与 Windows 双执行目标）、测试运行与结果核查。
- 五项预置能力：Prism 浏览器、MCP、skills、联网检索、跨会话记忆。出厂不预装 MCP 服务器，预置
  `prism` 浏览器技能。
- 权限边界：三档范围 + 一次性审批（ADR-0005）。

不含：

- 旧研究助手业务（晨报、研究问答、Notion/Gmail、课程与门户）。
- 插件系统（只做扩展点）、语义检索与独立记忆库、OS 级沙箱、预算上限。

## 运行环境

- 界面：Windows 上的 Electron 工作台，内嵌本地 Web UI；界面语言为中文。
- 内核：WSL 单实例，由工作台通过 `wsl.exe`
  启动；本地 HTTP/SSE（127.0.0.1 随机端口）通信，见 ADR-0003。
- 执行目标：WSL（默认）与 Windows（interop，经 `/mnt/c` 访问文件），限制见 ADR-0002。
- 数据目录：WSL 家目录 `~/.prism/`（会话、配置、回执）。
- 文档：中文为主，README 提供英文版。

## 能力明细

### 文件与命令

- 工作区内读写与测试自动执行；工作区外按权限审批。
- 命令工具带显式执行目标 `environment: wsl | windows`。Windows 目标经 WSL
  interop 调用程序，启动时转换工作目录，读取输出时处理编码差异。
- 不做 OS 级沙箱；范围档约束文件工具的路径。

### 浏览器

- 内核进程内使用 Playwright 作为浏览器引擎（ADR-0006）：默认 Chromium，可选择 Firefox 或 WebKit；Chromium 系经 CDP 通道，并可接管运行中的 Chrome/Edge 以保留登录态。
- 沿用既有语义：观察、目标引用、关系证据、单步动作与输入回执；内核管理自己的标签页。
- 动作默认自动执行，可在设置中改为需要审批。
- broker/CLI 保留给外部 agent，不进入首版验收。

### MCP

- 通过配置文件接入外部 MCP 服务器；出厂不预装。

### Skills

- 按目录约定加载 `SKILL.md`；出厂预置 `prism` 技能。

### 联网检索

- 内置 `web_search`（默认 DeepSeek，可配置来源）与 `web_fetch`（拒绝内网目标）。

### 会话与记忆

- pi 式会话：JSONL 会话树（条目带 `id`/`parentId`），按工作区分组存储。
- 压缩：接近上下文上限自动压缩，保留最近约 15k
  tokens（可配）；支持手动压缩；原始条目保留。
- 指令文件：`AGENTS.md` 自全局向工作目录链式加载；工作区内的嵌套文件在探索到时惰性加载。
- 工作台交互：会话列表（按工作区分组）、继续、新建、压缩、删除、搜索；分叉（fork/tree）数据结构预留，首版不提供界面。
- 不设独立记忆库与语义检索（ADR-0004）。

## 权限

- 三档权限范围：只读 / 工作区可写（默认）/ 完全访问。
- 越界动作需要审批：携带理由、只允许一次、不记忆批准；审批在工作台完成。
- 模型：默认 DeepSeek API（OpenAI 兼容），可配置任意 OpenAI 兼容端点。无每月预算上限。

## 验收

- 五项预置能力全部就绪后，由用户指定一个真实小需求，一次性验收：从工作台发起，在内核中完成，界面展示会话、工具过程、代码改动与产物。
- 开发期允许实现者自测（含偶尔真实任务），不属于验收。

## 开发方式

- 最小内核 + 扩展点；按层构建，先最小闭环再逐项接入预置能力。
- 依赖与代码从零建立；旧实现与旧测试已移除。

## 后续方向（不承诺）

- 接入 CLI
  Anything 增强工具能力；外部 agent 复用浏览器 broker/CLI；OS 级沙箱；会话分叉界面。
