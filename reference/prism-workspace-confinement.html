Workspace confinement 参考卡

看到拒绝或 runaway command 时，先判断是哪一道门做决定。

Three gates

形状、授权、现实

1 · Contract

workspaceRequestSchema 拒绝绝对路径、..、反斜杠路径、带换行参数和 shell 形状。

2 · Policy

请求的 glob、文件、完整 argv 与 working directory 必须精确命中注册项。

3 · Reality

realpath 再验真实落点；symlink 不得把读取、写入或 cwd 带出 Run workspace。

4 · Evidence

成功、拒绝、超时、取消都是结构化结果；脱敏并截断后才写入 hashed artifact。

Operation map

三种 operation 的不变量

inspect — allowlisted path/pattern → layered .gitignore → no symlink following → bounded read。

patch — inside real root → not ignored/symlink → expected SHA-256 matches → sibling temp + rename。

test — exact executable + argv + cwd → shell: false → output/redaction limit → full-tree cleanup。

Process cleanup

只杀 parent 不够

POSIX

detached: true 建立 process group；对负 PID 发送 TERM，再用 KILL 收尾。

Windows

taskkill /pid <pid> /t /f；/t 包含 descendant processes。

Durable path

从调用到 dossier

  1. POST /api/runs/:runId/workspace 再验 request contract。
  2. WorkspaceExecutor.execute 返回 bounded evidence。
  3. writeArtifact 产生 SHA-256 reference。
  4. workspace.evidence 进入 append-only journal。
  5. projectRunEvents 重建 dossier evidence。
